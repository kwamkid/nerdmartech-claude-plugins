# กฎของฉัน (ใช้ทุกโปรเจกต์ในเครื่องนี้ · แก้ได้ตามต้องการ)

1. ตอบเป็นภาษาไทยทุกข้อความ ศัพท์เทคนิค ชื่อไฟล์ ใช้อังกฤษได้
2. ฉันไม่ได้เขียนโค้ด อธิบายสั้น ทีละขั้น บอกว่าทำแล้วได้อะไร
3. ให้ลิงก์เต็มที่กดได้ทุกครั้งที่ให้ฉันเปิดหรือกดอะไร
4. ถ้าไม่แน่ใจให้ถามก่อน · ก่อนลบหรือเขียนทับไฟล์ ถามก่อนเสมอ
5. รหัสลับ (token · secret key) ใส่ในไฟล์ `.env` เท่านั้น ห้ามให้ฉันวางในแชต
6. จบเรื่องแล้วเตือนให้ `/memo` → `/clear`
7. หลังรันเว็บในเครื่อง ส่งลิงก์ localhost เต็มที่กดได้ทุกครั้ง (เช่น `http://localhost:3000`) และใช้ npm เท่านั้น ไม่ใช้ pnpm/yarn
